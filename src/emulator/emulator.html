Bridge: connecting…

    📱 Connect a phone or local emulator to see its screen here

    Mirrors and controls either your own USB-connected Android phone, or a free local Android emulator app running on this PC (BlueStacks, LDPlayer, NoxPlayer, MEmu, Windows Subsystem for Android) — pick a preset above (or type its host:port) and click Connect; it then appears in the "Phone" dropdown like any other device. Everything goes through adb via a local bridge at ws://127.0.0.1:8787 — nothing leaves your machine, no Android Studio, no cloud account. One-time setup: in the bridge/ folder of this project run npm install && npm run setup, then keep npm start running.
