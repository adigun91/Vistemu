    Remote device farm (optional, advanced)

    This extension cannot run real Android/iOS binaries by itself — a browser extension sandbox has no OS virtualization. If you already operate (or subscribe to) a device-farm/emulator-streaming service that exposes a browser-embeddable URL (e.g. a self-hosted Android emulator over noVNC/WebRTC), you can store its URL template here and open it from the emulator toolbar.
